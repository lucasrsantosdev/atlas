# Mosaic

Mosaic é uma camada de orquestração para modelos de IA.

## MVP

- Frontend: React + Vite
- Backend: FastAPI
- Database: SQLite
- Modelo inicial: Qwen 3B
- API: REST
- Streaming: SSE

## Estado

Fase 1 — Foundation, primeiro incremento:

- estrutura inicial;
- FastAPI;
- configuração;
- SQLite;
- endpoint `/health`;
- frontend React + Vite;
- teste básico da API.

Conversations e integração com Qwen serão implementados somente no próximo incremento.
