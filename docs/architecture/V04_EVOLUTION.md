# Atlas 0.4 evolution

0.4 closes the software-core architecture with capability-based model routing, bounded agent state machine, hybrid memory/knowledge retrieval, governed tools, persistent observability hooks, MCP adapters, and a simulated Hardware Gateway.

## Production boundary
The scores are target-readiness scores for the Atlas 1.0 architecture. Physical hardware validation, OS-grade sandboxing and external MCP transport interoperability remain environment-dependent acceptance gates and are not claimed as physically validated by this repository alone.
