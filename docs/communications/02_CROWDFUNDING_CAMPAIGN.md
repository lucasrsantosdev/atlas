# 🌎 VISÃO DA CAMPANHA

## A pergunta que iniciou o projeto

> **E se sua inteligência artificial não precisasse desaparecer quando a internet acaba, uma API fecha ou um modelo deixa de existir?**

Foi a partir dessa pergunta que surgiu o Projeto Atlas.

A proposta é pesquisar, construir e documentar uma plataforma de Inteligência Artificial pessoal capaz de funcionar prioritariamente de forma local.

O objetivo não é criar apenas mais um chatbot.

O objetivo é construir uma arquitetura capaz de preservar:

- identidade;
- memória;
- conhecimento;
- histórico;
- princípios;
- ferramentas;
- capacidade de aprendizado;
- capacidade de interação com o mundo físico.

---

# 1. O PROBLEMA

Hoje grande parte das soluções modernas de Inteligência Artificial depende de:

```text
Internet
   +
APIs externas
   +
Infraestrutura de terceiros
   +
Modelos controlados por empresas
   +
Dados processados por serviços externos
```

Se algum desses componentes deixa de existir, muitas das capacidades do sistema também desaparecem.

O Atlas nasce de uma pergunta:

> **Até onde conseguimos construir uma IA pessoal que continue funcionando localmente e cuja identidade, memória e conhecimento não estejam presos a um único modelo, equipamento ou fornecedor?**

---

# 2. O QUE É O ATLAS

O Atlas será construído como um ecossistema modular.

```text
                    ATLAS
                      │
              ┌───────┴───────┐
              │               │
         ATLAS CORE        ATLAS BODY
              │               │
     ┌────────┼────────┐      │
     │        │        │      ├── Mini Atlas
   Memory   Models    RAG     ├── Atlas Car
     │        │        │      ├── Atlas House
     └────────┼────────┘      ├── Atlas Arm
              │               ├── Atlas Air
         ATLAS ROUTER         └── Atlas Work
              │
      ┌───────┼─────────────┐
      │       │             │
    Fast   Reasoning    Engineering
   Code     Science       Vision
              │
          Emergency
```

A proposta arquitetural é:

```text
IDENTIDADE ≠ MODELO

MEMÓRIA ≠ MODELO

ATLAS ≠ COMPUTADOR ESPECÍFICO
```

O modelo poderá ser substituído.

O hardware poderá ser substituído.

A conexão poderá desaparecer.

A continuidade do sistema deverá permanecer.

---

# 3. PRINCÍPIO CENTRAL

O Atlas será desenvolvido segundo o princípio:

# OFFLINE FIRST

Internet poderá melhorar suas capacidades.

Mas não deverá ser necessária para sua existência.

O objetivo é permitir localmente:

- conversa;
- memória;
- RAG;
- consulta documental;
- programação;
- biblioteca;
- modelos especializados;
- voz;
- visão;
- automação;
- robótica;
- recuperação de conhecimento.
